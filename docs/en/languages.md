# Languages

Karman supports **English**, **Português (BR)** and **Español**.

## Switch the language
1. Open **Ultrahand** (ZL + ZR + D-Pad Down).
2. Open the **Karman** package and pick a language.
3. Close and reopen Ultrahand.

> **Heads up:** the switch copies a whole `config.ini` over Ultrahand's, so it **resets Ultrahand's other settings** (key combo, theme, wallpaper). Re-apply those afterwards, or rely on Ultrahand's own *Settings → Language* if you only want to change the UI language.

## What it covers
| Part | Language is set by |
|---|---|
| Ultrahand UI | The Karman package (above) or Ultrahand's own settings |
| Sphaira, DBI, Goldleaf, Checkpoint, JKSV, games | The **Switch system language** (System Settings → System → Language) |
| Hekate / Nyx | English only: Hekate has no language setting |

Karman adds overlays for another app only after its config key is verified (see [customize](customize.md)).
