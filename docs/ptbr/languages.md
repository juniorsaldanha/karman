# Idiomas

O Karman suporta **English**, **Português (BR)** e **Español**.

## Trocar o idioma
1. Abra o **Ultrahand** (ZL + ZR + D-Pad para baixo).
2. Abra o pacote **Karman** e escolha um idioma.
3. Feche e abra o Ultrahand de novo.

> **Atenção:** a troca copia um `config.ini` inteiro por cima do do Ultrahand, então **redefine as outras configurações do Ultrahand** (combinação de teclas, tema, wallpaper). Aplique-as de novo depois, ou use o *Settings → Language* do próprio Ultrahand se você só quer mudar o idioma da interface.

## O que é coberto
| Parte | O idioma é definido por |
|---|---|
| Interface do Ultrahand | O pacote Karman (acima) ou as configurações do próprio Ultrahand |
| Sphaira, DBI, Goldleaf, Checkpoint, JKSV, jogos | Normalmente o **idioma do sistema do Switch** (Configurações → Sistema → Idioma). Não verificado em todos os apps: se um app tiver configuração de idioma própria, mude nela |
| Hekate / Nyx | Somente inglês: o Hekate não tem configuração de idioma |

O Karman só adiciona sobreposições para outro app depois que a chave de configuração dele é verificada (veja [personalizar](customize.md)).
